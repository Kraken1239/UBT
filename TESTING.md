# Проверки UBT.AI

Этот отчёт описывает конкретное покрытие; он не означает, что проверены все возможные ситуации или качество материалов подтверждено преподавателем.

Последний прогон: **26 автоматических тестов прошли**, расширенный сценарий Chromium прошёл. Живой OpenAI API не вызывался.

## Автоматические серверные проверки

Команда: `python3 -m unittest discover -s tests -v` (Windows: `py -m unittest discover -s tests -v`).

- Регистрация, хеширование пароля, cookie-сессия, неверный пароль, вход из второго браузера/клиента, выход.
- Изоляция аккаунтов: чужие результаты и практика недоступны.
- Проверка ответов на сервере и отсутствие ключей в незавершённом тесте/практике.
- Повторная и одновременная отправка результата: одна запись, исходный результат не перезаписывается.
- Неверная практика → следующая задача → верный ответ без суточной блокировки; сохранение обеих проверок.
- Исчерпание вариантов: практика продолжается с явной отметкой повтора, без заявления об освоении навыка.
- Все 10 предметов на RU/KK/EN: профиль, каталог, запуск, успешная сдача и открытие разбора.
- Просроченный тест, неверные параметры, CSRF/Origin, лимит запросов.
- Импорт банка, дублирующий импорт, метаданные проверки, приоритет проверенных материалов.
- Миграция старой SQLite-базы без удаления существующих записей.
- Чтение UTF-8 явно, независимо от кодировки Windows.
- Проверка схемы всех 200 диагностических и 200 связанных заданий, уникальности вариантов ответа и покрытия предметов/языков.
- Независимый пересчёт 180 новых числовых задач: проценты, квадратные уравнения, скорость, количество вещества, двоичная система.
- Готовое объяснение в обсуждении без обязательного ввода: правильный ответ, причина и разбор последней проверенной практики.
- AI: подготовленный режим без ключа, корректный запрос с рассуждениями, история диалога, недоступность сервиса, отклонённый ключ, лимит/баланс и некорректный ответ API. Успех и отказы провайдера моделируются, реальный платный запрос не выполняется.

## Chromium: пользовательский сценарий

Команда: `python3 tests/browser_smoke.py`. Нужны Python Playwright и Chromium. Для нестандартного пути браузера — переменная `UBT_CHROMIUM`.

- Регистрация через интерфейс и прохождение пяти вопросов с ошибками.
- В разборе: два неверных ответа подряд, новые задачи, затем верный ответ **без выхода со страницы**.
- Возврат к конкретному разбору через историю: результат и обсуждение сохранены.
- Ошибка AI оставляет текст в форме и кнопку активной для повторного запроса.
- Первичное понимание отображается в прогрессе; перезагрузка и перезапуск сервера сохраняют аккаунт/историю.
- Вход во втором браузере видит те же результаты.
- Все 12 комбинаций языка и профильной пары: пять нужных предметов, запуск профильного теста, возврат назад с сохранением выбранного ответа.
- Отмена ухода оставляет тест открытым; подтверждение возвращает в обзор.
- Отмена отправки пустого теста и последующая подтверждённая отправка.
- AI-интерфейс с тестовым ответом: текст экранируется, HTML не исполняется.
- Выход, неверный пароль и возможность повторного входа.
- Мобильная ширина 390 px без горизонтального переполнения, отсутствие JS/CSP-ошибок.

## Что пока не подтверждено

- Живой OpenAI API: нужен ключ с доступом и балансом. Тестовый ответ не доказывает работу реального аккаунта провайдера.
- Полная проверка приложения в Windows: выполнена проверка явного UTF-8; остальные автоматические прогоны — Linux/Chromium.
- Полноценное соответствие официальному ЕНТ и преподавательская проверка всех формулировок/переводов.
- Долговременное улучшение обучения, нагрузочный пилот и публичное размещение.
