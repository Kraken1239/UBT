# UBT.AI — исправленная демоверсия

Замените `index.html` в репозитории RafaelloRaftRD/ubt-platform этим файлом. Сохраните изменение в основной ветке и дождитесь обновления GitHub Pages.

Дизайн и структура исходного сайта сохранены. Добавлено по 5 диагностических вопросов и 5 повторных заданий для каждого из 9 доступных предметов. Каталог показывает три обязательных предмета и два предмета выбранного профиля.

Исправлены сохранение результатов, история, изоляция локальных профилей, восстановление сессии после обновления, настройки имени/класса/языковой предпочтительности/пары предметов, проверка повторного задания, обновление статуса навыков, таймер, предупреждения о пропусках и выходе из теста, повторная запись результатов. В истории доступны ссылки на разбор ошибок. Навигация доступна на узких экранах.

Это локальная демоверсия: email выбирает профиль в текущем браузере, защищённого входа нет. Данные не синхронизируются между устройствами. Пояснения подготовлены заранее, запросов к LLM нет. Языковое предпочтение сохраняется; вопросы и интерфейс остаются на английском. Вопросы демонстрационные, не официальный банк ЕНТ. Для настоящих аккаунтов нужны серверная авторизация и база данных.

Проверка логики: `node verify.cjs` из папки, содержащей index.html. Проверены хранение после повторного чтения, разделение пользователей, смена профиля, подсчёт баллов, защита от дублирования попытки и правильная/неправильная повторная проверка. Браузерное визуальное тестирование не выполнено.

Для ручной проверки: создайте локальный профиль, пройдите тест с ошибкой, обновите страницу, откройте историю и разбор, отправьте неверный ответ на повторное задание, затем откройте разбор заново и решите правильно. Проверьте изменение статуса навыка и сохранение после обновления. Смените профильную пару в Profile и проверьте каталог.
