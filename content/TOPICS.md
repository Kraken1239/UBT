# Темы демонстрационного банка RU/KK

Для каждого предмета предусмотрены 5 тем по 2 диагностических вопроса на
русском и казахском языках. У каждого вопроса есть отдельное парное задание
для практики по тому же навыку. Всего: 100 диагностических и 100 парных
заданий на каждом из этих языков. Английские 50 вопросов и их практика сохранены.

| Предмет | Темы |
| --- | --- |
| Математическая грамотность | Проценты; среднее арифметическое; пропорции; вероятность; совместная работа |
| Грамотность чтения | Главная мысль; вывод; цель автора; факт и подтверждение; последовательность событий |
| История Казахстана | Казахское ханство; независимость; национальная валюта; исторические источники; археология |
| Профильная математика | Квадратные уравнения; линейные уравнения; функции; площадь треугольника; степени |
| Информатика | Системы счисления; единицы информации; переменные; циклы; логические выражения |
| Физика | Скорость; второй закон Ньютона; закон Ома; плотность; механическая работа |
| Биология | Клетка; фотосинтез; генетика; кровообращение; экология |
| Химия | Количество вещества; строение атома; сохранение массы; массовая доля; изотопы |
| Всемирная история | Древние цивилизации; Возрождение; промышленная революция; Вторая мировая война; международное сотрудничество |
| Основы права | Право, обязанность и запрет; разделение властей; права человека; договор; презумпция невиновности и доказательства |

Генерация: `python scripts/expand_demo.py`. Источник оригинальных упражнений —
`scripts/demo_topics.py`; генератор заменяет только RU/KK и сохраняет значения
английских записей. Новые идентификаторы имеют префикс `topics-v2-`;
сохранённые попытки продолжают использовать свои снимки вопросов.

Это учебные демопримеры, не полный охват программы ЕНТ и не банк,
проверенный преподавателем. Материалы и формулировки составлены для проекта.
Справочные источники для отдельных фактов:

- [Государственная независимость Казахстана](https://www.gov.kz/article/19305?lang=en).
- [История национальной валюты, Национальный Банк](https://nationalbank.kz/en/page/currency-history).
- [Жанибек хан, Институт истории и этнологии](https://iie.kz/?p=26061).
- [История ООН](https://www.un.org/en/about-us/history-of-the-un).
- [Всеобщая декларация прав человека](https://www.un.org/about-us/universal-declaration-of-human-rights), статьи 7, 11, 12, 19, 26.

Ссылки помогают проверить факты и не означают лицензирование текстов
источников, официальное одобрение вопросов или преподавательскую проверку.
